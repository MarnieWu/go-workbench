# Automated sources only propose candidates / 自动来源只能提出候选任务

## 中文

通过 Source Subscription 发现的内容只能创建 Capture 和 Candidate，不能直接创建 Task。已授权来源并不代表其中每条内容都应该进入任务系统，因此用户审核仍然是采集输入和工作台正式任务之间的边界。本次四天 MVP 不实现通用抓取框架；确定第一个具体来源后，再实现满足该来源所需的最小连接器。

## English

Content discovered through a Source Subscription creates Captures and Candidates, never Tasks directly. An approved source does not imply that every item from that source is actionable, so user review remains the boundary between collected input and the workbench's task system of record. The four-day MVP does not include a generic ingestion framework; the minimum connector will be implemented only after the first concrete source is selected.
