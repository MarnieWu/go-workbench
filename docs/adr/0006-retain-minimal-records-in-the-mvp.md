# Retain minimal records in the MVP / MVP 保留最小必要记录

## 中文

MVP 不提供自动清理或永久删除，并仅保存 Capture、Rejected Candidate、Source Evidence 和 Audit Event 所需的最小内容。这样可以避免在删除语义和恢复路径尚未完成前误删来源与审计证据；可配置保留期限、隐私删除和凭据撤销后的历史数据处理列入 MVP 后首批补强项。

## English

The MVP provides no automatic cleanup or permanent deletion and stores only the minimum content required for Captures, rejected Candidates, Source Evidence, and Audit Events. This avoids destroying provenance and audit evidence before deletion semantics and recovery paths are complete; configurable retention, privacy deletion, and historical-data handling after credential revocation are immediate post-MVP hardening items.
