# Preserve source evidence / 保留不可变来源证据

## 中文

用户可以在接受 Candidate 前编辑标题、描述、Project 和 Label，但原始 Capture 与 Source Evidence 保持不可变。可编辑建议与不可变来源分离，使用户能够修正任务表述，同时保留任务从何而来的可靠证据。

## English

The user can edit a Candidate's title, description, Project, and Labels before acceptance, but the original Capture and Source Evidence remain immutable. Separating editable proposals from immutable provenance lets the user correct task wording without losing reliable evidence of where the task originated.
